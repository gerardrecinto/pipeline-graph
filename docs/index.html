pipeline-graph

A GraphQL API over CI/CD data (services, pipelines, runs), written in Go.

docker run -p 8080:8080 ghcr.io/gerardrecinto/pipeline-graph:latest
curl -s localhost:8080 -d '{"query":"{ runs(first: 2, status: FAILED) { totalCount edges { cursor node { id status pipeline { name } } } } }"}'
  • Relay style cursor pagination with a status filter, first capped at 100
  • Per-request batching: 40 runs cost one pipeline lookup, proven by a test
  • Depth limit, body size cap, token-protected mutation with input validation
  • /healthz and Prometheus /metrics, graceful shutdown
  • Race tests with an 85% coverage gate, staticcheck, govulncheck, CodeQL
  • Releases ship checksums signed with Sigstore, and the image is signed too

Source on GitHub. A personal project, not a production system.
